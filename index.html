What is Raiku?

Raiku is a high-performance coordination layer for Solana, reengineering block building from first principles to deliver deterministic execution, sub-30ms pre-confirmations, and guaranteed block inclusion. It solves Solana's congestion issues (up to 75% tx failure during peaks) by creating a fair two-sided marketplace for blockspace, empowering developers, validators, traders, and institutions with predictable, scalable infrastructure.

Using Solana's trusted validators via a lightweight Sidecar, 500+ global edge nodes, and an advanced scheduling engine, Raiku enables applications in finance, AI, DePIN, and gaming. Development started July 2024; devnet live since Dec 2024, testnet with partners (Kiln, Figment, Everstake, Chorus One, Blockdaemon) operational.

How It Works

Raiku decouples block building from Solana L1, creating a parallel execution layer. Developers submit txs to nearest edge nodes; the Coordination Engine runs slot auctions and schedules via advanced engine. Validators deploy Raiku Sidecar for inclusion guarantees.

  1. Submission: Txs to low-latency nodes for processing.
  2. Auction & Schedule: Pre-book or bid for slots; deterministic outcomes.
  3. Execution: Sidecar integrates with validators for secure inclusion.
  4. Confirmation: Sub-30ms pre-conf with >99.9% finality; supports global accounts for shared state.

Empowers HFT, oracles, and node ops with edge compute for 30-50ms speeds. Testnet live; v2 SDK for devs in late 2025.
